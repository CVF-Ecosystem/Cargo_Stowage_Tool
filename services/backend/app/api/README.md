# API backend

**Trách nhiệm:** Nhận thao tác từ giao diện, gọi domain, trả dữ liệu và kết quả kiểm.

**Dùng từ mốc:** M1+.

**Không thuộc thư mục này:** Không chứa quy tắc nghiệp vụ; quy tắc nằm trong `domain/`.

Hiện chỉ là khung thư mục theo [roadmap v0.2](../../../../docs/roadmaps/SCST_ROADMAP_TONG_THE_DE_XUAT.md); chưa có code. Nội dung được thêm theo SPEC và WORK_ORDER của từng mốc.

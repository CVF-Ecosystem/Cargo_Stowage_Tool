# Giao tiếp backend

**Trách nhiệm:** Gọi API backend theo contract trong `contracts/`; nơi đặt client và kiểu dữ liệu dùng chung ở frontend.

**Dùng từ mốc:** M1+.

**Không thuộc thư mục này:** Không chứa logic nghiệp vụ; không gọi trực tiếp AI provider.

Đã có client gọi API M1, kiểm contract version, timeout/xử lý lỗi và kiểu TS sinh trong generated/. Lời gọi request viết tay; kiểu dữ liệu sinh từ OpenAPI.
